# ACB Judo — site web

Site statique de l'**ACB Judo** (section judo de l'Athlétic Club de Bobigny).
Déployé via GitHub Pages.

## Structure
- `index.html` — accueil
- `club.html` — le club, code moral, équipe, lieux
- `cours.html` — cours & horaires (filtrables)
- `tarifs.html` — tarifs & inscription
- `galerie.html` — galerie & actualités
- `contact.html` — contact & dojos
- `marque.html` — identité / design system (non indexé)
- `assets/` — CSS, JS, images

## Développement
Site 100% statique : ouvrir `index.html` ou servir le dossier
(`python3 -m http.server`).

## À compléter (fournis par le club)
Photos réelles, grades des professeurs, confirmation tarifs/horaires saison courante,
logo définitif (3 pistes dans `marque.html`).
